# 💰 Expense Tracker App

A powerful mobile expense tracking application built with React Native and Firebase. Track personal expenses, create groups, split bills with friends, and manage budgets all in one place.

## ✨ Features

- 🔐 **Authentication** - Sign up/Login with email
- 💸 **Personal Expenses** - Track individual spending
- 👥 **Group Expenses** - Create groups, add members, split bills
- 🔄 **Real-time Sync** - Instant updates across all members
- 📊 **Analytics** - Spending charts and insights
- 💰 **Budget Management** - Set monthly limits
- 🎨 **Modern UI** - Clean design with gradient headers

## 🛠️ Tech Stack

- React Native + Expo
- TypeScript
- Redux Toolkit
- Firebase (Auth + Firestore)
- Expo Router
